🌌 Infinite Canvas UI V6 구현 요약 문서 (최종 통합본)
To: 안티그래비티 (Anti-Gravity)
Subject: 무한 캔버스 UI V6 최종 업데이트 - 뷰 전환, 상세 모달, 커스텀 로고 및 리스트 인터랙션 적용안
1. 개요 (Overview)
기존 무한 캔버스(Grid View) 기반의 탐색 경험을 유지하면서, 사용자 편의를 위한 세로형 리스트 뷰(List View) 전환 기능과 상세 정보 모달(Detail Modal) 창을 추가한 최종 V6 버전입니다.
또한, 레퍼런스를 반영한 Y2K 메탈릭 타이포그래피 로고 적용 및 화면 밀도(Gap) 최적화, 마우스 호버(Hover) 시의 직관적인 색상 반전 효과까지 모든 UI/UX 디테일업이 완료되었습니다.
2. 핵심 기능 및 UI/UX 구현 명세 (Core Features & Updates)
① 뷰 모드 전환 (View Mode Toggle)
* 기능 요약: 하단 좌측의 ALL LIST / VIEW GRID 버튼을 클릭해 무한 캔버스와 세로 리스트를 부드럽게 전환(Crossfade)합니다.
* Tech 스펙:
   * 상태값(viewMode)에 따라 렌더링을 분기하며, 리스트 뷰 진입 시 캔버스의 물리 엔진 연산을 일시 중단시켜 리소스(CPU/GPU)를 최적화했습니다.
   * 리스트 아이템에 마우스를 올렸을 때(Hover), 레퍼런스와 동일하게 배경이 하얗게 밝아지고 내부 텍스트와 태그가 검은색으로 반전되는 가독성 강조 효과(group-hover)를 적용했습니다.
② 드래그 방지 및 상세 정보 모달 (Bottom-up Detail Modal)
* 기능 요약: 카드를 클릭하면 화면 하단에서 위로 부드럽게 올라오는 상세 정보창(Modal)을 구현했습니다.
* Tech 스펙:
   * Drag vs Click 구분 로직: 마우스 다운~업 사이의 이동 거리(dragDistance)를 누적 계산하여, 10px 이상 드래그했을 경우 클릭 이벤트가 무시되도록 처리해 오작동을 방지했습니다.
   * 모달 애니메이션은 Tailwind의 translate-y와 transition-transform 큐빅 베지에(Cubic-bezier) 곡선을 활용해 부드럽게 제어했습니다.
③ Y2K 메탈릭 타이포그래피 로고 (Custom Logo)
* 기능 요약: 좌측 상단 로고를 'ビショジョ // アーカイブ' 텍스트로 변경하고, 일본 애니메이션 풍의 화려한 3D 메탈릭 스타일을 적용했습니다.
* Tech 스펙:
   * 텍스트에 -skew-x-[12deg]를 적용해 역동성을 주고, WebkitTextStroke를 사용해 두꺼운 외곽선 그림자 레이어와 전면 메탈릭 그라데이션 레이어를 겹쳐(Z-index Layering) 3D 효과를 구현했습니다.
   * 브라우저 리사이징 시 레이어가 어긋나지 않도록 whitespace-nowrap과 w-fit으로 안전하게 고정했습니다. (불필요한 별모양 그래픽 제거 완료)
④ 무한 캔버스 물리 엔진 & 밀도 최적화 (Physics Engine & Density)
* 기능 요약: 우주 공간처럼 끝없이 이어지며 빙판 위를 미끄러지는 듯한 관성 스크롤을 제공합니다.
* Tech 스펙:
   * 간격(Gap) 최소화: 카드 간격을 12px로 극단적으로 좁히고 지그재그 폭을 100px로 조정하여, 화면에 빈틈없이 콘텐츠가 꽉 차 보이는 고밀도(High-density) 레이아웃을 완성했습니다.
   * 패턴 & 색상 붕괴 방지: 홀수/짝수 열(6 Columns) 동기화로 무한 루프 시 지그재그 패턴이 끊기지 않으며, 그리드 컬러링 알고리즘을 통해 인접한 카드끼리 같은 네온 색상(10종 팔레트)이 겹치지 않도록 설계되었습니다.
⑤ 필터 컨트롤 바 개선 (Filter Control Bar)
* 기능 요약: 레퍼런스 UI 구조에 맞춰 토글 버튼을 캡슐 형태 밖으로 독립시키고, 내부 필터 버튼 텍스트를 'ゲーム', 'アニメ'로 변경했습니다.
3. 전체 코드 (React 단일 파일 구성)
import React, { useState, useRef, useEffect } from 'react';

// --- [Mock Data & Constants] ---
const CARD_W = 260;
const CARD_H = 360;
const GAP = 12; // 최적화된 고밀도 간격
const COLS = 6; // 패턴 붕괴 방지용 짝수 열
const ROWS = 5;
const STAGGER_Y = 100; 

const CHUNK_WIDTH = COLS * (CARD_W + GAP); 
const CHUNK_HEIGHT = ROWS * (CARD_H + GAP);

const NEON_COLORS = [
 '#0a84ff', '#64d2ff', '#30d158', '#5e5ce6', '#00cdbc', // Cool
 '#ff453a', '#ff9f0a', '#ffd60a', '#ff375f', '#bf5af2'  // Warm
];

const CARDS_DATA = [];
for (let i = 0; i < COLS * ROWS; i++) {
 const col = i % COLS;
 const row = Math.floor(i / COLS);

 // 인접 색상 중복 방지 알고리즘
 const forbiddenColors = new Set();
 if (col > 0) forbiddenColors.add(CARDS_DATA[i - 1].neonColor); 
 if (row > 0) forbiddenColors.add(CARDS_DATA[i - COLS].neonColor); 

 const availableColors = NEON_COLORS.filter(color => !forbiddenColors.has(color));
 const selectedColor = availableColors[Math.floor(Math.random() * availableColors.length)];

 CARDS_DATA.push({
   id: i,
   title: ["日本昔ばなし", "雪おんな", "かぐや姫", "浦島太郎", "桃太郎", "さるかに合戦"][Math.floor(Math.random() * 6)] + ` Vol.${i + 1}`,
   tags: ["神話", "アクション", "ファンタジー", "ロマンス", "コメディ", "歴史"].slice(0, Math.floor(Math.random() * 2) + 1),
   author: ["スタジオジブリ風", "新海誠スタイル", "鳥山明リスペクト", "手塚治虫オマージュ"][Math.floor(Math.random() * 4)],
   imageUrl: `https://picsum.photos/seed/${i + 800}/400/600`,
   neonColor: selectedColor
 });
}

// --- [Components] ---

// 1. 개별 카드 컴포넌트 (Grid View 용)
const Card = ({ data, onClick }) => {
 const cardRef = useRef(null);

 const handleMouseMove = (e) => {
   if (!cardRef.current) return;
   const rect = cardRef.current.getBoundingClientRect();
   cardRef.current.style.setProperty('--mouse-x', `${e.clientX - rect.left}px`);
   cardRef.current.style.setProperty('--mouse-y', `${e.clientY - rect.top}px`);
 };

 return (
   <div
     ref={cardRef} onMouseMove={handleMouseMove} onClick={() => onClick(data)}
     className={`relative rounded-[32px] overflow-hidden cursor-pointer group transition-transform duration-500 ease-out hover:scale-[1.04] hover:-translate-y-2 shrink-0`}
     style={{ 
       width: `${CARD_W}px`, height: `${CARD_H}px`,
       boxShadow: `0 0 40px -5px ${data.neonColor}50, 0 15px 35px -10px rgba(0,0,0,0.8)`
     }}
   >
     <div className="relative z-10 w-full h-full bg-[#111113] overflow-hidden flex flex-col justify-end p-6">
       <div className="absolute inset-0 bg-cover bg-center transition-transform duration-700 group-hover:scale-110 opacity-60" style={{ backgroundImage: `url(${data.imageUrl})` }} />
       <div className="absolute inset-0 bg-gradient-to-t from-black/95 via-black/40 to-transparent" />
       <div className="absolute inset-0 pointer-events-none rounded-[32px] z-10 mix-blend-screen" style={{ border: `2px solid ${data.neonColor}60`, boxShadow: `inset 0 0 80px 5px ${data.neonColor}70, inset 0 0 20px 2px ${data.neonColor}90` }} />
       <div className="pointer-events-none absolute inset-0 opacity-0 group-hover:opacity-100 transition-opacity duration-300 z-10 mix-blend-overlay" style={{ background: 'radial-gradient(600px circle at var(--mouse-x) var(--mouse-y), rgba(255,255,255,0.3), transparent 40%)' }} />
       
       <div className="relative z-20 text-white flex flex-col gap-2 drop-shadow-lg">
         <h3 className="text-2xl font-bold leading-tight text-white/95 tracking-wide">{data.title}</h3>
         <p className="text-xs text-white/60 font-medium">Author: {data.author}</p>
         <div className="flex flex-wrap gap-2 mt-2">
           {data.tags.map((tag, idx) => (
             <span key={idx} className="px-3 py-1 text-[11px] font-medium rounded-full bg-black/40 backdrop-blur-md border border-white/20 text-white/80">{tag}</span>
           ))}
         </div>
       </div>
     </div>
   </div>
 );
};

// 2. 무한 루프 반복 단위 블록
const BoardChunk = ({ offsetX, offsetY, onCardClick }) => {
 return (
   <div className="absolute top-0 left-0 pointer-events-auto" style={{ width: `${CHUNK_WIDTH}px`, height: `${CHUNK_HEIGHT}px`, transform: `translate3d(${offsetX}px, ${offsetY}px, 0)` }}>
     {CARDS_DATA.map((card, index) => {
       const col = index % COLS;
       const row = Math.floor(index / COLS);
       const x = col * (CARD_W + GAP);
       const stagger = col % 2 !== 0 ? STAGGER_Y : 0;
       const y = row * (CARD_H + GAP) + stagger;
       return (
         <div key={card.id} className="absolute top-0 left-0" style={{ transform: `translate3d(${x}px, ${y}px, 0)` }}>
           <Card data={card} onClick={onCardClick} />
         </div>
       );
     })}
   </div>
 );
};

// 3. 리스트 뷰 컴포넌트 (List View 용)

               </span>

        ))}
      </div>

 )

// 4. 메인 애플리케이션
export default function App() {
 const [viewMode, setViewMode] = useState('grid');
 const viewModeRef = useRef(viewMode);
 
 const [activeCard, setActiveCard] = useState(null);
 const [isModalOpen, setIsModalOpen] = useState(false);
 const dragDistance = useRef(0);

 const containerRef = useRef(null);
 const isDragging = useRef(false);
 const requestRef = useRef();

 const target = useRef({ x: 0, y: 0 });
 const current = useRef({ x: 0, y: 0 });
 const dragStart = useRef({ x: 0, y: 0 });
 const mousePos = useRef({ x: 0, y: 0 });
 const velocity = useRef({ x: 0, y: 0 });

 useEffect(() => { viewModeRef.current = viewMode; }, [viewMode]);

 const openModal = (card) => {
   setActiveCard(card);
   setTimeout(() => setIsModalOpen(true), 10);
 };

 const closeModal = () => {
   setIsModalOpen(false);
   setTimeout(() => setActiveCard(null), 700);
 };

 const handleCardClick = (card) => {
   if (dragDistance.current > 10) return; // 드래그 시 클릭 방지
   openModal(card);
 };

 const handleMouseDown = (e) => {
   if (viewMode !== 'grid') return;
   if (e.target.closest('button') || e.target.closest('a')) return;
   isDragging.current = true;
   dragStart.current = { x: e.clientX, y: e.clientY };
   mousePos.current = { x: e.clientX, y: e.clientY };
   velocity.current = { x: 0, y: 0 };
   dragDistance.current = 0;
   document.body.style.cursor = 'grabbing';
 };

 const handleMouseMove = (e) => {
   if (!isDragging.current || viewMode !== 'grid') return;
   const deltaX = e.clientX - mousePos.current.x;
   const deltaY = e.clientY - mousePos.current.y;
   velocity.current = { x: deltaX, y: deltaY };
   target.current.x += deltaX;
   target.current.y += deltaY;
   dragDistance.current += Math.abs(deltaX) + Math.abs(deltaY);
   mousePos.current = { x: e.clientX, y: e.clientY };
 };

 const handleMouseUp = () => {
   isDragging.current = false;
   document.body.style.cursor = 'default';
 };

 const updatePhysics = () => {
   if (viewModeRef.current === 'list') {
     requestRef.current = requestAnimationFrame(updatePhysics);
     return;
   }

   if (!isDragging.current) {
     target.current.x += velocity.current.x;
     target.current.y += velocity.current.y;
     velocity.current.x *= 0.93; 
     velocity.current.y *= 0.93;
   }

   current.current.x += (target.current.x - current.current.x) * 0.15; 
   current.current.y += (target.current.y - current.current.y) * 0.15;

   let wrapX = current.current.x % CHUNK_WIDTH;
   let wrapY = current.current.y % CHUNK_HEIGHT;

   if (wrapX > CHUNK_WIDTH / 2) wrapX -= CHUNK_WIDTH;
   if (wrapX < -CHUNK_WIDTH / 2) wrapX += CHUNK_WIDTH;
   if (wrapY > CHUNK_HEIGHT / 2) wrapY -= CHUNK_HEIGHT;
   if (wrapY < -CHUNK_HEIGHT / 2) wrapY += CHUNK_HEIGHT;

   if (current.current.x - wrapX !== 0) target.current.x -= (current.current.x - wrapX);
   if (current.current.y - wrapY !== 0) target.current.y -= (current.current.y - wrapY);
   
   current.current.x = wrapX;
   current.current.y = wrapY;

   if (containerRef.current) containerRef.current.style.transform = `translate3d(${current.current.x}px, ${current.current.y}px, 0)`;
   requestRef.current = requestAnimationFrame(updatePhysics);
 };

 useEffect(() => {
   window.addEventListener('mousemove', handleMouseMove);
   window.addEventListener('mouseup', handleMouseUp);
   requestRef.current = requestAnimationFrame(updatePhysics);
   return () => {
     window.removeEventListener('mousemove', handleMouseMove);
     window.removeEventListener('mouseup', handleMouseUp);
     cancelAnimationFrame(requestRef.current);
   };
 }, []);

 const offsets = [-1, 0, 1];

 return (
   <div className="w-screen h-screen overflow-hidden bg-[#0a0a0a] select-none relative font-sans text-zinc-100" onMouseDown={handleMouseDown}>
     
     <div className="absolute inset-0 bg-[radial-gradient(ellipse_at_center,_var(--tw-gradient-stops))] from-zinc-900/40 via-[#0a0a0a] to-[#0a0a0a] pointer-events-none z-0" />

     {/* --- GRID VIEW --- */}
     <div className={`absolute inset-0 transition-opacity duration-700 ease-in-out ${viewMode === 'grid' ? 'opacity-100' : 'opacity-0'}`}>
       <div ref={containerRef} className="absolute top-1/2 left-1/2 will-change-transform z-10">
         <div className="absolute" style={{ transform: `translate(-${CHUNK_WIDTH/2}px, -${CHUNK_HEIGHT/2}px)`}}>
           {offsets.map((y) => (
             offsets.map((x) => (
               <BoardChunk key={`${x}-${y}`} offsetX={x * CHUNK_WIDTH} offsetY={y * CHUNK_HEIGHT} onCardClick={handleCardClick} />
             ))
           ))}
         </div>
       </div>
       <div className={`fixed top-[45%] left-1/2 -translate-x-1/2 -translate-y-1/2 pointer-events-none z-0 flex flex-col items-center opacity-30 transition-opacity duration-500`}>
         <h1 className="text-8xl font-black text-transparent bg-clip-text bg-gradient-to-br from-white to-zinc-700 tracking-tighter text-center leading-tight mix-blend-overlay">Drag to<br/>Discover</h1>
       </div>
     </div>

     {/* --- LIST VIEW --- */}
     <ListView data={CARDS_DATA} isVisible={viewMode === 'list'} onCardClick={openModal} />

     {/* --- UI OVERLAYS --- */}
     {/* 3D Typography Logo */}
     <div className="fixed top-8 left-10 z-50 pointer-events-none select-none flex flex-col items-start transform -skew-x-[12deg] drop-shadow-[0_10px_20px_rgba(0,0,0,0.5)] transition-all">
       <div className="relative z-10 w-fit">
         <h1 className="text-6xl font-black tracking-tighter absolute top-[4px] left-[4px] text-slate-900 whitespace-nowrap z-10" style={{ WebkitTextStroke: '12px #0f172a' }}>ビショジョ</h1>
         <h1 className="text-6xl font-black tracking-tighter relative bg-gradient-to-b from-white via-cyan-300 to-blue-600 bg-clip-text text-transparent whitespace-nowrap z-20" style={{ WebkitTextStroke: '2px #cffafe' }}>ビショジョ</h1>
       </div>
       <div className="relative z-20 ml-12 -mt-3 w-fit">
         <h1 className="text-5xl font-black tracking-tighter absolute top-[4px] left-[4px] text-slate-900 whitespace-nowrap" style={{ WebkitTextStroke: '10px #0f172a' }}>アーカイブ</h1>
         <h1 className="text-5xl font-black tracking-tighter relative bg-gradient-to-b from-blue-100 via-indigo-400 to-purple-600 bg-clip-text text-transparent whitespace-nowrap" style={{ WebkitTextStroke: '2px #e0e7ff' }}>アーカイブ</h1>
       </div>
     </div>

     {/* Nav */}
     <div className="fixed top-8 right-8 z-50 flex gap-6 text-[13px] font-bold tracking-widest text-white/60">
        <button className="hover:text-white transition-colors uppercase">About</button>
        <button className="hover:text-white transition-colors uppercase">Company</button>
     </div>

     {/* Bottom Control Bar */}
     <div className="fixed bottom-10 left-1/2 -translate-x-1/2 z-50 flex items-center gap-8">
       <button onClick={() => setViewMode(prev => prev === 'grid' ? 'list' : 'grid')} className="flex items-center justify-center text-white font-black text-sm tracking-widest transition-transform hover:scale-105 active:scale-95 drop-shadow-md">
         {viewMode === 'grid' ? (
           <><svg className="w-6 h-6 mr-2" fill="none" stroke="currentColor" viewBox="0 0 24 24"><path strokeLinecap="round" strokeLinejoin="round" strokeWidth="3" d="M8 6h12M8 12h12M8 18h12M4 6h.01M4 12h.01M4 18h.01" /></svg>ALL LIST</>
